## 🎯 Objetivo do Projeto

O objetivo deste projeto é desenvolver uma aplicação web com interface intuitiva, organizada e responsiva, colocando em prática os conhecimentos adquiridos durante as aulas de desenvolvimento web.

O sistema busca permitir o acesso, o cadastro, o gerenciamento e a visualização de informações relacionadas ao tema escolhido pela equipe.

---

## 💻 Sobre o Projeto

O projeto consiste no desenvolvimento de um sistema web composto por cinco telas principais, que representam as funcionalidades essenciais da plataforma.

As telas desenvolvidas são:

1. **Login:** tela de acesso ao sistema.
2. **Menu:** página principal para navegação entre as funcionalidades.
3. **Cadastro do Criador:** formulário para registrar informações do criador.
4. **Cadastro da Obra:** formulário para cadastrar novas obras.
5. **Listagem:** tela destinada à visualização dos registros cadastrados.

A interface foi desenvolvida considerando a organização dos elementos, a facilidade de navegação e a experiência do usuário.
